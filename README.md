### v1.1.0 (2026-04-29) Update:<br>

- 🔊 **アプリ別出力デバイス選択**: 各フェーダーのドロップダウンから、アプリごとに出力先デバイスを個別に切り替えられます。選択は次回起動時にも保持されます。
- 🖥️ **システムトレイ常駐**: × ボタンでウィンドウを閉じた際にトレイへ最小化。タスクトレイのアイコンをダブルクリックで再表示、右クリックメニューから終了できます。（設定でオン/オフ切替可能）
- 🚀 **Windows 起動時の自動起動**: Windows ログイン時に inuMixer を自動的に起動できます。（設定でオン/オフ切替可能）
- 🔌 **デバイス接続・切断の自動検出**: USBオーディオインターフェイスなど外部デバイスの抜き差しを検出し、デバイス一覧を自動更新します。（設定でオン/オフ切替可能）
- 📊 **ピークホールド表示**: 各フェーダーのピークメーターに金色のホールドラインを追加。瞬間的な最大音量を約 1.5 秒間表示した後、なめらかに減衰します。

<br>

inuMixer は、Windowsでのオーディオ体験を快適にする、DAW風の縦型ボリュームミキサーです。<br>
「ゲーム中に裏で鳴っているDiscordやブラウザの音量を、サッと調整したい」という個人的なニーズから生まれました。<p>

### ✨ 主な機能

- フェーダーUI: 直感的で視認性の高いスライダー操作。
- アプリごとの音量管理: 起動中のアプリケーションを自動検知し、個別に音量調整・ミュートが可能。
- マスターフェーダー: システム全体の音量を一括コントロール。
- アプリ別出力デバイス選択: フェーダー下のドロップダウンから、アプリごとに出力先デバイスを変更できます。
- ピークホールド表示: ピークメーターに金色のホールドラインを表示。瞬間的な最大音量を視覚的に確認できます。
- ドラッグ＆ドロップ並び替え: フェーダーの位置を自由に入れ替え可能。配置は次回起動時にも記憶されます。
- 表示フィルター: 不要なアプリ（システム音など）を非表示設定できます。
- システムトレイ常駐: × ボタンでトレイへ最小化し、バックグラウンドで動作し続けます。
- Windows 自動起動: ログイン時に自動で起動できます。
- デバイス自動検出: 外部オーディオデバイスの接続・切断を自動で検知し一覧を更新します。
- オーバーレイ表示:
  - 常に手前に表示: ゲームや作業画面の上に常駐可能。
  - 透明度調整: 邪魔にならないよう、ウィンドウの透過率を変更可能。


### 🎮 操作方法
- 音量調整: フェーダーの上で マウスホイールをスクロール します。（スライダーのドラッグ操作も可能）
- ミュート切替: フェーダーの上で マウスホイールをクリック（中クリック） します。（下のMuteボタンも可能）
- 配置変更: フェーダーを 左ドラッグ して好きな場所に移動します。
- 設定: 右上の ⚙️ アイコンから、表示・非表示にするアプリを選択できます。
